## Task A â€” one place that answers "which side has the edge above this frame"

New module `app/strategy/edge_side.py`.

```python
def edge_side(frames: Mapping[Timeframe, pd.DataFrame], at: pd.Timestamp, entry: Timeframe) -> Side | None
```

- Reads the **D1 regime** from the lane's H1 frame: shift the close-stamped index back one hour, resample
  to `1D`, take only bars closed at `at`, a 50-day rolling mean of the close.
  - `BUY` when the close is over a mean that is rising (bull),
  - `SELL` when the close is under a mean that is falling (bear),
  - `None` when neither (mixed, or fewer than 50 closed D1 bars).
- `entry` is the entry timeframe and must be **smaller than D1**; raise `ValueError` if it is not, so the
  rule can never be read from a frame at or below the entry frame.
- Needs 50 closed D1 bars, so about 1,200 closed H1 bars. If the frame is shorter, return `None` - never
  guess from a short mean.
- Pure function, no I/O, no clock reads.

Hand-worked tests: bull, bear, both mixed cases, exactly 50 bars, 49 bars, a D1 bar that has not closed
yet (the same shape as `test_an_unclosed_h4_bar_never_reaches_the_zigzag`), and the `ValueError`.

## Task C â€” the vessel for the weighted decision

New module `app/strategy/weighing.py`. No strategy calls it yet; this round only builds and tests it.

```python
@dataclass(frozen=True)
class Weight:
    name: str          # the reading's name
    weight: float      # how much it counts, >= 0
    wants: str         # "high" | "low" | "true" | "false": which direction supports the trade

@dataclass(frozen=True)
class Scale:
    weights: tuple[Weight, ...]
    threshold: float   # the score needed to trade, 0..1

def score(readings: Mapping[str, float | bool | None], scale: Scale) -> ScoreResult
```

`ScoreResult` carries: the total score **normalised to 0..1 over the weights that could be read**, the
list of readings that supported the trade, the list that opposed it, and the list that was missing. A
reading absent or `None` is **left out of both the numerator and the denominator** - never counted as
agreement. An empty scale, or one where nothing could be read, scores `0.0` and supports nothing.

Boolean readings: `wants="true"` scores its full weight when the value is `True`, zero when `False`.
Numeric readings: the caller passes values already normalised to 0..1, and `wants="low"` scores
`weight * (1 - value)`. Document that normalisation is the caller's job - do not invent one.

Hand-worked tests, every number worked out by hand in the test: all agree, all disagree, a mix, a missing
reading changing the denominator, `wants="low"`, an empty scale, a zero weight, and a threshold exactly
met (document and test whether `>=` or `>` - pick `>=` and say so).

import bots  # noqa: E402

ROOT = Path(__file__).resolve().parents[2]
FIT = (pd.Timestamp("2025-10-20", tz="UTC"), pd.Timestamp("2026-10-24", tz="UTC"))
WIDE = [1.0, 1.25, 1.5, 2.0, 3.0]


def day_end(at: pd.Timestamp) -> pd.Timestamp:
    """``run``'s own deadline for a trade opened at ``at``: 07:00 Bangkok the next morning."""
    th = at.tz_convert(bots.TH)
    return (pd.Timestamp(th.date(), tz=bots.TH) + pd.Timedelta(days=1, hours=7)).tz_convert("UTC")


def path_stats(m1: pd.DataFrame, t: bots.Trade, p: bots.P) -> dict:
    """Walk the real M1 path once and read off everything the entry's geometry needs.

    The counterfactual stops get the SAME DEADLINE the original trade had (07:00 Bangkok the next day,
    and ``max_hours``), not the moment the original happened to exit: the original exited early *because*
    it was stopped, so cutting the wider stop off there would answer the question with itself. The first
    version of this file did exactly that and gave a win rate that did not move with the stop width -
    which is impossible, and is what exposed the mistake.
    """
    x = m1[(m1.index >= t.at) & (m1.index <= t.extra["closed"])]
    if x.empty:
        return {}
    sell = t.side == "SELL"
    risk = abs(t.stop - t.entry)
    hi, lo = x.high.to_numpy(float), x.low.to_numpy(float)
    adverse = (hi.max() - t.entry) if sell else (t.entry - lo.min())
    favour = (t.entry - lo.min()) if sell else (hi.max() - t.entry)
    out = {"mae_r": adverse / risk, "mfe_r": favour / risk, "risk": risk}
    until = day_end(t.at)
    for k in WIDE:
        wider = bots.Trade(
            t.bot, t.side, t.at, t.entry, t.entry + k * risk if sell else t.entry - k * risk, t.tp
        )
        got = bots.settle(m1, wider, until, p)
        out[f"r_x{k}"] = got.r * k  # back into R of the ORIGINAL risk, so the k columns are comparable
        out[f"out_x{k}"] = got.out
    return out


def table(df: pd.DataFrame, title: str) -> None:
    print(f"\n### {title}  ({len(df)} trades)\n")
    if df.empty:
        print("no trades")
        return
    win, lose = df[df.r > 0], df[df.r <= 0]
    print("| group | trades | median MAE (R) | 75th MAE | median MFE (R) | mean R |")
    print("|---|---|---|---|---|---|")
    for name, g in (("winners", win), ("losers", lose), ("all", df)):
        if g.empty:
            continue
        print(
            f"| {name} | {len(g)} | {g.mae_r.median():.2f} | {g.mae_r.quantile(0.75):.2f} | "
            f"{g.mfe_r.median():.2f} | {g.r.mean():+.3f} |"
        )
    print("\n| stop width | mean R a trade | win rate | trades stopped out |")
    print("|---|---|---|---|")
    for k in WIDE:
        col = df[f"r_x{k}"]
        print(f"| x{k} | {col.mean():+.3f} | {(col > 0).mean():.0%} | {(col <= -0.9 * k).sum()} |")

    f = {t: to_frame(hs.load("FBS-Demo", "XAUUSD", t, None, None)) for t in (Timeframe.M1, Timeframe.H1)}

MEAN_DAYS = 50


def regimes(h1: pd.DataFrame) -> pd.DataFrame:
    """One row per CLOSED D1 bar: its close, the 50-day mean, and the regime label."""
    opens = h1.copy()
    opens.index = pd.DatetimeIndex(opens.index) - pd.Timedelta(hours=1)  # frames are close-stamped
    d1 = opens.resample("1D").agg({"high": "max", "low": "min", "close": "last"}).dropna()
    d1["mean50"] = d1.close.rolling(MEAN_DAYS).mean()
    d1["rising"] = d1.mean50.diff() > 0
    over = d1.close > d1.mean50
    d1["regime"] = "mixed"
    d1.loc[over & d1.rising, "regime"] = "bull"
    d1.loc[~over & ~d1.rising, "regime"] = "bear"
    d1.loc[d1.mean50.isna(), "regime"] = "unknown"
    d1["closed_at"] = d1.index + pd.Timedelta(days=1)  # the bar is readable only after it closes
    return d1


def label(d1: pd.DataFrame, at: pd.Timestamp) -> str:
    usable = d1[d1.closed_at <= at]
    return str(usable.regime.iloc[-1]) if len(usable) else "unknown"


def window_of(at: pd.Timestamp) -> str:
    th = at.tz_convert(bots.TH)
    ny = at.tz_convert(bots.NY)
    if pd.Timestamp("07:00").time() < th.time() <= pd.Timestamp("09:00").time():
        return "Asia 07-09"
    if pd.Timestamp("13:00").time() < th.time() <= pd.Timestamp("15:00").time():
        return "London 13-15"
    if pd.Timestamp("08:00").time() < ny.time() <= pd.Timestamp("11:30").time():
        return "NY open"
    return "other"


def cells(df: pd.DataFrame, by: list[str], title: str, least: int = 8) -> None:
    print(f"\n### {title}\n")
    print(f"| {' | '.join(by)} | trades | win | R a trade | total R | in fit / unseen R |")
    print(f"|{'---|' * (len(by) + 5)}")
    for key, g in df.groupby(by):
        if len(g) < least:
            continue
        keys = key if isinstance(key, tuple) else (key,)
        fit, uns = g[g.fitted], g[~g.fitted]
        both = f"{fit.r.mean():+.3f} / {uns.r.mean():+.3f}" if len(fit) and len(uns) else "-"
        print(
            f"| {' | '.join(str(k) for k in keys)} | {len(g)} | {(g.r > 0).mean():.0%} | "
            f"{g.r.mean():+.3f} | {g.r.sum():+.1f} | {both} |"
        )
    small = sum(len(g) for _, g in df.groupby(by) if len(g) < least)
    if small:
        print(f"\n({small} trades sit in cells under {least} trades and are left out)")

    print("# The three bots' edge by market condition (P25's split)\n")

    )

    cells(df, ["bot", "window"], "Each bot by the owner's session windows")
    cells(df, ["bot", "regime", "window"], "Both together", least=6)
    df.to_csv(HERE / "edge_trades.csv", index=False)


if __name__ == "__main__":
    main()

```python
def edge_side(frames: Mapping[Timeframe, pd.DataFrame], at: pd.Timestamp, entry: Timeframe) -> Side | None
```

  guess from a short mean.

## Task C Ã¢â‚¬â€ the vessel for the weighted decision

New module `app/strategy/weighing.py`. No strategy calls it yet; this round only builds and tests it.

```python
@dataclass(frozen=True)
class Weight:
    name: str          # the reading's name
    weight: float      # how much it counts, >= 0
    wants: str         # "high" | "low" | "true" | "false": which direction supports the trade

@dataclass(frozen=True)
class Scale:
    weights: tuple[Weight, ...]
    threshold: float   # the score needed to trade, 0..1

def score(readings: Mapping[str, float | bool | None], scale: Scale) -> ScoreResult
```

`ScoreResult` carries: the total score **normalised to 0..1 over the weights that could be read**, the
list of readings that supported the trade, the list that opposed it, and the list that was missing. A
reading absent or `None` is **left out of both the numerator and the denominator** - never counted as
agreement. An empty scale, or one where nothing could be read, scores `0.0` and supports nothing.

Boolean readings: `wants="true"` scores its full weight when the value is `True`, zero when `False`.
Numeric readings: the caller passes values already normalised to 0..1, and `wants="low"` scores
`weight * (1 - value)`. Document that normalisation is the caller's job - do not invent one.

Hand-worked tests, every number worked out by hand in the test: all agree, all disagree, a mix, a missing
reading changing the denominator, `wants="low"`, an empty scale, a zero weight, and a threshold exactly
met (document and test whether `>=` or `>` - pick `>=` and say so).

WIDE = [1.0, 1.25, 1.5, 2.0, 3.0]


def day_end(at: pd.Timestamp) -> pd.Timestamp:
    """``run``'s own deadline for a trade opened at ``at``: 07:00 Bangkok the next morning."""
    th = at.tz_convert(bots.TH)
    return (pd.Timestamp(th.date(), tz=bots.TH) + pd.Timedelta(days=1, hours=7)).tz_convert("UTC")


def path_stats(m1: pd.DataFrame, t: bots.Trade, p: bots.P) -> dict:
    """Walk the real M1 path once and read off everything the entry's geometry needs.

    The counterfactual stops get the SAME DEADLINE the original trade had (07:00 Bangkok the next day,
    and ``max_hours``), not the moment the original happened to exit: the original exited early *because*
    it was stopped, so cutting the wider stop off there would answer the question with itself. The first
    version of this file did exactly that and gave a win rate that did not move with the stop width -
    which is impossible, and is what exposed the mistake.
    """
    x = m1[(m1.index >= t.at) & (m1.index <= t.extra["closed"])]
    if x.empty:
        return {}
    sell = t.side == "SELL"
    risk = abs(t.stop - t.entry)
    hi, lo = x.high.to_numpy(float), x.low.to_numpy(float)
    adverse = (hi.max() - t.entry) if sell else (t.entry - lo.min())
    favour = (t.entry - lo.min()) if sell else (hi.max() - t.entry)
    out = {"mae_r": adverse / risk, "mfe_r": favour / risk, "risk": risk}
    until = day_end(t.at)
    for k in WIDE:
        wider = bots.Trade(
            t.bot, t.side, t.at, t.entry, t.entry + k * risk if sell else t.entry - k * risk, t.tp
        )
        got = bots.settle(m1, wider, until, p)
        out[f"r_x{k}"] = got.r * k  # back into R of the ORIGINAL risk, so the k columns are comparable
        out[f"out_x{k}"] = got.out
    return out


def table(df: pd.DataFrame, title: str) -> None:
    print(f"\n### {title}  ({len(df)} trades)\n")
    if df.empty:
        print("no trades")
        return
    win, lose = df[df.r > 0], df[df.r <= 0]
    print("| group | trades | median MAE (R) | 75th MAE | median MFE (R) | mean R |")
    print("|---|---|---|---|---|---|")
    for name, g in (("winners", win), ("losers", lose), ("all", df)):
        if g.empty:
            continue
        print(
            f"| {name} | {len(g)} | {g.mae_r.median():.2f} | {g.mae_r.quantile(0.75):.2f} | "
            f"{g.mfe_r.median():.2f} | {g.r.mean():+.3f} |"
        )
    print("\n| stop width | mean R a trade | win rate | trades stopped out |")
    print("|---|---|---|---|")
    for k in WIDE:
        col = df[f"r_x{k}"]
        print(f"| x{k} | {col.mean():+.3f} | {(col > 0).mean():.0%} | {(col <= -0.9 * k).sum()} |")

MEAN_DAYS = 50


def regimes(h1: pd.DataFrame) -> pd.DataFrame:
    """One row per CLOSED D1 bar: its close, the 50-day mean, and the regime label."""
    opens = h1.copy()
    opens.index = pd.DatetimeIndex(opens.index) - pd.Timedelta(hours=1)  # frames are close-stamped
    d1 = opens.resample("1D").agg({"high": "max", "low": "min", "close": "last"}).dropna()
    d1["mean50"] = d1.close.rolling(MEAN_DAYS).mean()
    d1["rising"] = d1.mean50.diff() > 0
    over = d1.close > d1.mean50
    d1["regime"] = "mixed"
    d1.loc[over & d1.rising, "regime"] = "bull"
    d1.loc[~over & ~d1.rising, "regime"] = "bear"
    d1.loc[d1.mean50.isna(), "regime"] = "unknown"
    d1["closed_at"] = d1.index + pd.Timedelta(days=1)  # the bar is readable only after it closes
    return d1


def label(d1: pd.DataFrame, at: pd.Timestamp) -> str:
    usable = d1[d1.closed_at <= at]
    return str(usable.regime.iloc[-1]) if len(usable) else "unknown"


def window_of(at: pd.Timestamp) -> str:
    th = at.tz_convert(bots.TH)
    ny = at.tz_convert(bots.NY)
    if pd.Timestamp("07:00").time() < th.time() <= pd.Timestamp("09:00").time():
        return "Asia 07-09"
    if pd.Timestamp("13:00").time() < th.time() <= pd.Timestamp("15:00").time():
        return "London 13-15"
    if pd.Timestamp("08:00").time() < ny.time() <= pd.Timestamp("11:30").time():
        return "NY open"
    return "other"

@dataclass
class P:
    retrace: tuple[float, float] = (0.382, 0.786)
    box: float = 0.25  # the box at most this share of the H1 leg tall
    buffer: float = 0.2  # the stop past the box by this share of the box height
    min_tp: float = 0.0  # the 5 USD floor, off since 2026-10-27 (it rejected 1 of 496 signals)
    min_r: float = 1.0
    tp_range: float = 0.5
    run: float = 1.2
    spread: float = 0.30
    exit_mode: str = "tp"  # tp | be | trail | struct (see the module docstring)
    be_at: float = 1.0  # the trade must be this many R ahead before the stop moves
    trail_min: int = 30  # 'trail': the stop follows the extreme of the last this many minutes of M1 bars
    struct_bars: int = 3  # 'struct': this many M5 closes back across the entry end the trade
    max_hours: float = (
        0  # the trade is closed at this bar's close after this many hours (0: at the day's end)
    )
    bots: tuple[str, ...] = ("DOWN", "UP", "RANGE")
    d1: bool = False  # the trend bots only with the D1 regime (the close against its 50-day mean)
    range_mode: str = "fade"  # fade: sell a sweep closed back; opposite: the same trigger, the other side;
    # break: an M5 close out of the box, traded with the break
    range_tf: str = "H4"  # where the box comes from: "H4", "H1" or "both" (the H4 box with H1 inside it)
    range_flat: bool = True  # the box frame must not be stepping up or down

def windows(day: pd.Timestamp) -> list[tuple[pd.Timestamp, pd.Timestamp]]:
    th, ny = pd.Timestamp(day.date(), tz=TH), pd.Timestamp(day.date(), tz=NY)
    return [
        ((th + pd.Timedelta(hours=7)).tz_convert("UTC"), (th + pd.Timedelta(hours=9)).tz_convert("UTC")),
        ((th + pd.Timedelta(hours=13)).tz_convert("UTC"), (th + pd.Timedelta(hours=15)).tz_convert("UTC")),
        (
            (ny + pd.Timedelta(hours=8)).tz_convert("UTC"),
            (ny + pd.Timedelta(hours=11, minutes=30)).tz_convert("UTC"),
        ),
    ]


def market(h1: pd.DataFrame) -> tuple[str, list]:  # the census only: the bots no longer switch on it
    sw, _ = zigzag(h1.high.to_numpy(float), h1.low.to_numpy(float))
    highs = [s for s in sw if s.kind == 1]
    lows = [s for s in sw if s.kind == -1]
    if len(highs) < 2 or len(lows) < 2:
        return "NONE", sw
    if highs[-1].price < highs[-2].price and lows[-1].price < lows[-2].price:
        return "DOWN", sw
    if highs[-1].price > highs[-2].price and lows[-1].price > lows[-2].price:
        return "UP", sw
    return "RANGE", sw


def settle(m1: pd.DataFrame, t: Trade, until: pd.Timestamp, p: P) -> Trade:
    """Walk the M1 bars from the entry to ``until``: the stop (moved by ``exit_mode``) and the take-profit, the
    worse of the two first when a bar holds both; else the last close. The spread is taken off once."""
    if p.max_hours:
        until = min(until, t.at + pd.Timedelta(hours=p.max_hours))
    x = m1[(m1.index >= t.at) & (m1.index < until)]
    sell = t.side == "SELL"
    risk = abs(t.stop - t.entry)
    hi = x.high.to_numpy()
    lo = x.low.to_numpy()
    cl = x.close.to_numpy()
    ix = x.index
    stop, best = t.stop, t.entry  # best: the furthest price reached in the trade's favour
    exit_px, out, when = None, ("time" if p.max_hours else "eod"), until
    back = 0  # 'struct': M5 closes in a row back across the entry
    for i in range(len(x)):
        if (hi[i] >= stop) if sell else (lo[i] <= stop):
            exit_px, out, when = stop, ("SL" if stop == t.stop else "trail"), ix[i]
            break
        if (lo[i] <= t.tp) if sell else (hi[i] >= t.tp):
            exit_px, out, when = t.tp, "TP", ix[i]
            break
        best = min(best, lo[i]) if sell else max(best, hi[i])
        ahead = (t.entry - best) if sell else (best - t.entry)
        if p.exit_mode in ("be", "trail") and ahead >= p.be_at * risk:
            moved = t.entry
            if p.exit_mode == "trail" and i >= 1:
                j = max(0, i - p.trail_min + 1)
                moved = float(hi[j : i + 1].max()) if sell else float(lo[j : i + 1].min())
            stop = min(stop, max(moved, t.entry)) if sell else max(stop, min(moved, t.entry))
        if p.exit_mode == "struct" and (i + 1) % 5 == 0:
            back = back + 1 if ((cl[i] > t.entry) if sell else (cl[i] < t.entry)) else 0
            if back >= p.struct_bars:
                exit_px, out, when = float(cl[i]), "struct", ix[i]
                break
    if exit_px is None:
        exit_px = float(cl[-1]) if len(x) else t.entry
    gain = (t.entry - exit_px) if sell else (exit_px - t.entry)
    t.r, t.out = (gain - p.spread) / risk, out
    t.extra["closed"] = when
    return t


def run(
    f: dict, params: P | dict[str, P], start: pd.Timestamp = START, end: pd.Timestamp = END
) -> list[Trade]:
    """Every bot of ``params`` (one P for all its bots, or one P per bot) side by side, each with its own
    position, so a trend trade and a range trade can be open at once."""
    per: dict[str, P] = params if isinstance(params, dict) else {b: params for b in params.bots}
    m1, h1 = f[Timeframe.M1], f[Timeframe.H1]
    h4 = h1.resample("4h").agg({"open": "first", "high": "max", "low": "min", "close": "last"}).dropna()
    m1 = m1[(m1.index >= start - pd.Timedelta(days=3)) & (m1.index < end + pd.Timedelta(days=2))]
    m5 = m1.resample("5min").agg({"open": "first", "high": "max", "low": "min", "close": "last"}).dropna()
    trades: list[Trade] = []
    busy = dict.fromkeys(per, start)  # each bot's own position: free again from this time
    for day in pd.date_range(start, end, freq="D"):
        if day.weekday() >= 5:
            continue
        day_end = (pd.Timestamp(day.date(), tz=TH) + pd.Timedelta(days=1, hours=7)).tz_convert("UTC")
        for w0, w1 in windows(day):
            bars = m5[(m5.index >= w0 - pd.Timedelta(hours=2)) & (m5.index < w1)]
            seen, sw, sw4 = None, [], []
            for i in range(len(bars)):
                t_close = bars.index[i] + pd.Timedelta(minutes=5)
                if t_close <= w0 or t_close > w1:
                    continue
                hx = h1[h1.index + pd.Timedelta(hours=1) <= t_close].iloc[-400:]
                if seen != len(hx):
                    seen = len(hx)
                    sw, _ = zigzag(hx.high.to_numpy(float), hx.low.to_numpy(float))
                    h4x = h4[h4.index + pd.Timedelta(hours=4) <= t_close].iloc[-300:]
                    sw4, _ = zigzag(h4x.high.to_numpy(float), h4x.low.to_numpy(float))
                if len(sw) < 3:
                    continue
                past = bars.iloc[: i + 1]
                for bot, p in per.items():
                    if t_close < busy[bot]:
                        continue  # this bot's own trade is still open
                    tr = signal(bot, sw, sw4, past, p, t_close)
                    if tr is None:
                        continue
                    before = m1[(m1.index >= t_close - pd.Timedelta(minutes=60)) & (m1.index < t_close)]
                    runup = (
                        (tr.entry - before.low.min()) if tr.side == "SELL" else (before.high.max() - tr.entry)
                    )
                    if p.run and runup > p.run * abs(tr.stop - tr.entry):
                        continue
                    tr = settle(m1, tr, day_end, p)
                    trades.append(tr)
                    busy[bot] = tr.extra["closed"]
    return sorted(trades, key=lambda x: x.at)


def stepping(sws: list) -> str:
    """'DOWN' (lower high and lower low), 'UP', or 'FLAT' - from the last two confirmed swings of each kind."""
    highs = [s for s in sws if s.kind == 1]
    lows = [s for s in sws if s.kind == -1]
    if len(highs) < 2 or len(lows) < 2:
        return "FLAT"
    if highs[-1].price < highs[-2].price and lows[-1].price < lows[-2].price:
        return "DOWN"
    if highs[-1].price > highs[-2].price and lows[-1].price > lows[-2].price:
        return "UP"
    return "FLAT"


def range_box(sw: list, sw4: list, p: P) -> tuple[float, float] | None:
    """(top, bottom) of the big-picture box, or None when that frame is not sideways."""
    big = sw4 if p.range_tf in ("H4", "both") else sw
    if len(big) < 2:
        return None
    if p.range_flat and stepping(big) != "FLAT":
        return None
    highs = [s.price for s in big if s.kind == 1]
    lows = [s.price for s in big if s.kind == -1]
    if not highs or not lows:
        return None
    top, floor = highs[-1], lows[-1]
    if top <= floor:
        return None
    if p.range_tf == "both":  # the H1 swings have to sit inside the H4 box
        h1h = [s.price for s in sw if s.kind == 1][-1:]
        h1l = [s.price for s in sw if s.kind == -1][-1:]
        if not h1h or not h1l or h1h[0] > top or h1l[0] < floor:
            return None
    return top, floor


def signal(bot: str, sw: list, sw4: list, past: pd.DataFrame, p: P, t: pd.Timestamp) -> Trade | None:
    """The bot's own setup on these bars, or None. Each bot tests its own structure, so a down leg and a range
    can hold at the same moment; the two trend bots cannot, their conditions being opposites."""
    price = float(past.close.iloc[-1])
    highs = [s for s in sw if s.kind == 1]
    lows = [s for s in sw if s.kind == -1]
    if len(highs) < 2 or len(lows) < 2:
        return None
    if bot in ("DOWN", "UP"):
        down = bot == "DOWN"
        stepping = (
            (highs[-1].price < highs[-2].price and lows[-1].price < lows[-2].price)
            if down
            else (highs[-1].price > highs[-2].price and lows[-1].price > lows[-2].price)
        )
        if not stepping:
            return None
        a, b = sw[-2], sw[-1]  # the last confirmed leg
        if (a.kind, b.kind) != ((1, -1) if down else (-1, 1)):
            return None
        leg = abs(a.price - b.price)
        if leg <= 0:
            return None
        for n in range(24, 5, -1):  # the longest box that still fits
            if len(past) < n + 1:
                continue
            box = past.iloc[-n - 1 : -1]
            top, floor = float(box.high.max()), float(box.low.min())
            if top - floor > p.box * leg:
                continue
            mid = (top + floor) / 2
            retr = (mid - b.price) / leg if down else (b.price - mid) / leg
            if not (p.retrace[0] <= retr <= p.retrace[1]):
                return None
            if down and price < floor:
                stop, tp = top + p.buffer * (top - floor), b.price
            elif not down and price > top:
                stop, tp = floor - p.buffer * (top - floor), b.price
            else:
                return None
            risk, reward = abs(stop - price), abs(price - tp)
            if reward < p.min_tp or reward < p.min_r * risk or (tp >= price if down else tp <= price):
                return None
            side = "SELL" if down else "BUY"
            return Trade(bot, side, t, price, stop, tp, extra={"retrace": round(retr, 2), "box": n})
        return None
    box = range_box(sw, sw4, p)
    if box is None:
        return None
    hh, ll = box
    bar = past.iloc[-1]
    rng = hh - ll
    if p.range_mode == "break":  # price leaves the box: the close through decides, no 'inside' gate
        prev = float(past.close.iloc[-2]) if len(past) > 1 else price
        if price > hh >= prev:
            stop, tp, side = hh - p.buffer * rng * 0.25, price + p.tp_range * rng, "BUY"
        elif price < ll <= prev:
            stop, tp, side = ll + p.buffer * rng * 0.25, price - p.tp_range * rng, "SELL"
        else:
            return None
        risk, reward = abs(stop - price), abs(tp - price)
        if risk <= 0 or reward < p.min_tp or reward < p.min_r * risk:
            return None
        return Trade("RANGE", side, t, price, stop, tp, extra={"range": round(rng, 1)})
    if not ll < price < hh:  # a fade is taken from inside the box only
        return None
    if bar.high > hh and bar.close < hh:
        stop = float(bar.high) + p.buffer * float(bar.high - bar.low)
        tp = price - p.tp_range * (price - ll)
        side = "SELL"
    elif bar.low < ll and bar.close > ll:
        stop = float(bar.low) - p.buffer * float(bar.high - bar.low)
        tp = price + p.tp_range * (hh - price)
        side = "BUY"
    else:
        return None
    if p.range_mode == "opposite":  # the same moment, the other side: stop and take-profit mirrored
        side = "BUY" if side == "SELL" else "SELL"
        stop, tp = 2 * price - stop, 2 * price - tp
    risk, reward = abs(stop - price), abs(tp - price)
    if reward < p.min_tp or reward < p.min_r * risk:
        return None
    return Trade("RANGE", side, t, price, stop, tp, extra={"range": round(rng, 1)})


def report(trades: list[Trade], title: str) -> None:
    df = pd.DataFrame([{"bot": t.bot, "side": t.side, "at": t.at, "r": t.r, "out": t.out} for t in trades])
    print(f"\n== {title}: {len(df)} trades ==")
    if not len(df):
        return
    print("| bot | trades | win % | R / trade (after spread) | total R | weeks + / - | worst streak |")
    print("|---|---|---|---|---|---|---|")
    for bot, g in [*df.groupby("bot"), ("ALL", df)]:
        wk = g.groupby(g["at"].dt.tz_convert(TH).dt.to_period("W")).r.sum()
        streak = cur = 0
        for r in g.r:
            cur = cur + 1 if r < 0 else 0
            streak = max(streak, cur)
        print(
            f"| {bot} | {len(g)} | {(g.r > 0).mean():.0%} | {g.r.mean():+.3f} | {g.r.sum():+.1f} | "
            f"{(wk > 0).sum()} / {(wk <= 0).sum()} | {streak} |"
        )

## 1. Does the D1 filter leave a workable system?

There is not enough evidence to call the filtered system workable. The CSV has 163 bull, 57 bear, 26 mixed, and 2 unknown trades. Applying the D1 direction to the trend bots leaves 76 UP trades in bull and 24 DOWN trades in bear: 100 historical trend entries. Those average about **−0.05 R per trade combined**. That is not evidence of an edge.

The RANGE data cannot tell us how many entries would survive: `edge_trades.csv` labels every RANGE trade’s side as `both`, and these are not a clean sample of the proposed directional range-break method. Measure that method separately.

I would keep the owner’s higher-timeframe side rule as a hard constraint, but treat “bull means BUY, bear means SELL” as a hypothesis to validate, not a proven profitable mapping. In particular, UP in bull loses **−0.118 R** overall and is negative in both splits. The regime label does not make an entry good just because its side agrees.

## 2. Should the three-bot shape change?

Yes: make the strategy logic **one directional trend method with a side input**, plus a separate range-break method. Keep three trader instances if that is useful for the account picture, but do not maintain mirrored UP and DOWN implementations as separate strategy concepts.

Preserve the account constraint with one shared position coordinator: at most two open positions, with the allowed combinations explicit. D1 should constrain each entry’s side; it should not silently change which methods can compete for those slots.

## 3. What is wrong with the weighted-score plan?

Besides fitting weights on the same 248 trades:

- With 132 candidate measures, feature hunting and trying variants can overfit even if the final weights look simple. Related readings can count the same evidence repeatedly.
- Winner/loser separation is not the same as predicting **net R**. It can favor readings associated with more winners while ignoring payoff size, stops, spreads, and losses.
- Missing readings change the denominator. A trade with only a few favorable readings can score highly if the more informative readings are missing.
- A score can combine methods or regimes where a reading’s meaning changes. Pooling them can hide opposite effects.
- “Measurable at the decision bar” needs strict point-in-time verification. A value can be available in a CSV yet still depend on a bar or indicator state that was not closed then.
- More indicators and thresholds mean more choices. Picking the best threshold after seeing results adds another layer of selection bias.

Compare score and gates on the same chronological, out-of-sample candidate trades with weights and thresholds locked in advance. Report **net R per calendar week including abstentions as zero**, trade count, drawdown, and trade rate; also compare at matched trade counts or risk budgets. Use a week-blocked uncertainty estimate, since trades from the same market week are not independent.

## 4. One change, and a one-week measure

I would first add the **hard D1 side veto** as an admission rule, with mixed or unavailable regimes producing no trade. It directly enforces the owner’s rule and prevents countertrend entries; it does not claim that aligned entries are profitable.

Within one week, the meaningful pass/fail number is **zero entries whose side opposes a clear D1 edge**. Also record eligible signals and their shadow net R, but one week’s realized R cannot establish an edge. Keep the rule fixed and judge profitability on a longer, predeclared forward sample.

One correction to the premise: “Losers never move in our favour at all” is too strong. The reported losing-trade median MFE is **0.17–0.68 R**, which is some favorable movement; it does not show that exits are irrelevant. The figures do support investigating selection, but they do not prove that selection is the whole problem.
