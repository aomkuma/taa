"""The trading day's plan, as a gate rather than a reminder (P26).

The owner, 2026-10-25: every trading day starts with the plan - the market's condition, yesterday's
levels, the trend, the side with the edge, the turn/go-on scenarios - written and summarised before
anything is traded. It was recorded as a principle (P26), as a knowledge-base entry and as a memory, and
on the evening of 2026-10-27 the engine still opened a DEMO session with no plan at all. The owner:
*"I went to the trouble of telling you to write it down as a principle."*

A note cannot stop anything. So the plan is now a **file whose presence is the permission**, exactly
like the kill switch: one ``stat`` per gate check, no tooling needed to satisfy it, and nothing to
forget. Without today's plan the mode gate fails and no broker order is sent; positions already open are
still managed, because refusing to manage them would be more dangerous than the missing plan.

**The day is the owner's trading day, 07:00 Thai to 07:00 Thai**, not the calendar date: a plan written
on Tuesday morning still covers Wednesday 02:00 Thai, in the middle of the New York session.
"""

from __future__ import annotations

import logging
from datetime import datetime, time, timedelta
from pathlib import Path
from zoneinfo import ZoneInfo

TH = ZoneInfo("Asia/Bangkok")
DAY_STARTS = time(7)  # the owner's trading day opens with the Asia window
DEFAULT_DIR = Path("data/plans")

log = logging.getLogger(__name__)


def trading_date(now: datetime) -> str:
    """The Thai trading day ``now`` belongs to, as ``YYYY-MM-DD``.

    02:00 Thai on Wednesday is still Tuesday's trading day; 07:00 Thai starts the new one.
    """
    th = now.astimezone(TH)
    return (th.date() - timedelta(days=1) if th.time() < DAY_STARTS else th.date()).isoformat()


class DayPlan:
    """Is today's plan written? Presence of the file is the whole answer."""

    def __init__(self, directory: Path | str = DEFAULT_DIR) -> None:
        self.directory = Path(directory)

    def path(self, now: datetime) -> Path:
        return self.directory / f"{trading_date(now)}.md"

    def exists(self, now: datetime) -> bool:
        """True when the day's plan file is there and not empty.

        An empty file is not a plan: a shell redirect that failed halfway would otherwise open the gate.
        """
        p = self.path(now)
        try:
            return p.is_file() and p.stat().st_size > 0
        except OSError:  # pragma: no cover - a vanished mount is the same as no plan
            log.warning("cannot read the day plan at %s; treating the day as unplanned", p)
            return False

    def write(self, now: datetime, text: str) -> Path:
        """Record the day's plan. Refuses to overwrite one: a day has one plan, added to, not replaced."""
        p = self.path(now)
        if self.exists(now):
            raise FileExistsError(f"the plan for {trading_date(now)} is already written: {p}")
        p.parent.mkdir(parents=True, exist_ok=True)
        p.write_bytes(text.encode("utf-8"))
        log.info("the plan for %s is recorded (%s)", trading_date(now), p)
        return p

class TestTheTradingDay:
    """07:00 Thai to 07:00 Thai, so a plan written on Tuesday morning still covers Wednesday's NY hours."""

    def test_the_day_turns_at_seven_in_the_morning_thai(self) -> None:
        assert trading_date(at(6, 59)) == "2026-10-26"  # still the previous trading day
        assert trading_date(at(7, 0)) == "2026-10-27"  # the Asia window opens the new one
        assert trading_date(at(23, 30)) == "2026-10-27"
        assert trading_date(at(2, 0, day=28)) == "2026-10-27"  # the middle of New York

    def test_it_reads_the_thai_clock_whatever_zone_the_moment_arrives_in(self) -> None:
        # 00:30 UTC on the 28th is 07:30 Thai: past the turn, so it is the 28th
        assert trading_date(datetime(2026, 10, 28, 0, 30, tzinfo=UTC)) == "2026-10-28"
        # 23:00 UTC on the 27th is 06:00 Thai on the 28th: BEFORE the turn, so still the 27th
        assert trading_date(datetime(2026, 10, 27, 23, 0, tzinfo=UTC)) == "2026-10-27"


class TestThePlanFile:
    def test_no_file_means_the_day_is_unplanned(self, tmp_path: Path) -> None:
        assert DayPlan(tmp_path).exists(at(9)) is False

    def test_a_written_plan_opens_the_day(self, tmp_path: Path) -> None:

    def test_an_empty_file_is_not_a_plan(self, tmp_path: Path) -> None:

    def test_yesterdays_plan_does_not_cover_today(self, tmp_path: Path) -> None:

        assert plan.exists(at(9, day=27)) is False

    def test_a_plan_written_in_the_morning_still_covers_the_new_york_hours(self, tmp_path: Path) -> None:

@dataclass(frozen=True, slots=True)
class GateResult:
    mode: TradingMode
    failures: tuple[tuple[GateCondition, str], ...]

    @property
    def passed(self) -> bool:
        return not self.failures

    @property
    def reason(self) -> Reason | None:
        if self.passed:
            return None
        if any(cond is GateCondition.MODE for cond, _ in self.failures):
            return Reason.ORDERS_NOT_ALLOWED_IN_MODE
        return Reason.LIVE_GATE_FAILED

    @property
    def failed_conditions(self) -> set[GateCondition]:
        return {cond for cond, _ in self.failures}


def confirmation_phrase(login: int | None) -> str:
    return f"I-ACCEPT-LIVE-RISK-{login}"

    SENDING â†’ PLACED â†’ FILLED | CANCELLED | EXPIRED            (a limit part of an entry plan, TAA-1207)
    UNKNOWN â†’ PLACED                                           (an unknown limit found resting)

- **Write-ahead:** the intent row (unique ``idempotency_key`` = signal key + part) is committed before
  anything is sent. A second attempt with the same key sends nothing and trips DUPLICATE_EXECUTION.
- **Pre-check:** ``order_check`` must answer 0.
- **Pre-send re-check** (time of check vs time of use), right before ``order_send``: the caller's checks
  (kill switch, breakers, connection, quote freshness, spread, price drift, signal expiry). Any problem means
  NOT_EXECUTED.
- **Retcodes** (Â§A12 matrix): success / partial â†’ filled; requote or price change â†’ at most one retry with
  a fresh price if the re-check still passes (counts as a failure); ``None`` or an unknown-class code â†’
  UNKNOWN, DUPLICATE_EXECUTION trips and nothing is resent until reconciled; permanent errors â†’ rejected;
  symbol restrictions â†’ SYMBOL_RESTRICTED for that symbol; no money / autotrading disabled / account-mode
  conflicts â†’ the kill switch is activated (HALT); too many requests â†’ ORDER_FAILURES. Every failed send
  counts toward ORDER_FAILURES.
- **Entry plans** (TAA-1207): the market part(s) go first; the limit parts are placed only when every market
  part is protected, each with the plan's stop and target, a cancel time (``cancel_after``: the limit
  lifetime, never past the Friday cut-off) and a broker-side expiration a few minutes later as a backstop.
  The pending order's filling is chosen by ``order_check`` (RETURN, then the market filling; without the
  expiration if the symbol refuses one). :mod:`app.engine.plan_supervisor` follows the resting parts.
- **Post-fill guard:** slippage feeds the SLIPPAGE breaker; a fill whose risk at the stop exceeds the plan by
  more than ``realized_risk_tolerance`` is reduced (or closed, per policy); a position without its stop gets
  it re-attached, or is closed and UNPROTECTED_POSITION trips.
"""

class OrderManager:
    def __init__(
        self,
        db: Database,
        execution: ExecutionGateway,
        market: MarketDataGateway,
        monitor: BreakerMonitor,
        kill_switch: KillSwitch,
        clock: Clock,
        config: ExecutionConfig,
        *,
        deviation_points: int,
        presend: PreSendCheck,
        bus: EventBus | None = None,
        limit_deadline: LimitDeadline | None = None,
    ) -> None:
        self.db = db
        self.execution = execution
        self.market = market
        self.monitor = monitor
        self.kill_switch = kill_switch
        self.clock = clock
        self.config = config
        self.builder = RequestBuilder(deviation_points)
        self.presend = presend
        self.bus = bus
        self.limit_deadline = limit_deadline or (lambda _symbol, now: now + timedelta(hours=4))

    # --- state ------------------------------------------------------------------------------------------

    def _move(
        self, sess: Session, row: OrderIntentRow, new: IntentState, detail: str = "", **fields: object
    ) -> None:
        old = IntentState(row.state)
        if new not in TRANSITIONS[old]:
            raise IllegalTransition(f"intent {row.intent_id}: {old} -> {new} is not allowed")
        row.state = new.value
        row.updated_at = self.clock.now_utc()
        if detail:
            row.detail = (f"{row.detail}; {detail}" if row.detail else detail)[:2000]
        for key, value in fields.items():
            setattr(row, key, value)
        log.info("intent %s %s -> %s %s", short_id(row.intent_id), old.value, new.value, detail)

    def transition(self, intent_id: str, new: IntentState, detail: str = "", **fields: object) -> None:
        with self.db.session() as sess:
            row = sess.get(OrderIntentRow, (LOCAL_ENGINE, intent_id))
            if row is None:
                raise TaaError(f"unknown intent {intent_id}")
            self._move(sess, row, new, detail, **fields)

    def plan_groups(self) -> dict[int, str]:
        """Position ticket -> entry plan, for every intent of a plan that became a position (TAA-1207)."""
        with self.db.session() as sess:
            rows = sess.execute(
                select(OrderIntentRow.position_ticket, OrderIntentRow.plan_key).where(
                    OrderIntentRow.position_ticket.is_not(None), OrderIntentRow.plan_key != ""
                )
            ).all()
        return {int(ticket): str(plan) for ticket, plan in rows if ticket is not None}

    def plan_parts_closed(self, open_tickets: set[int]) -> set[int]:
        """Of *open_tickets*, those whose entry plan has another part that became a position and is closed
        now (TAA-1207: the remaining parts go to break-even)."""
        groups = self.plan_groups()
        closed = {plan for ticket, plan in groups.items() if ticket not in open_tickets}
        return {t for t in open_tickets if groups.get(t) in closed}

    def row(self, intent_id: str) -> OrderIntentRow:
        with self.db.session() as sess:
            row = sess.get(OrderIntentRow, (LOCAL_ENGINE, intent_id))
            if row is None:
                raise TaaError(f"unknown intent {intent_id}")
            sess.expunge(row)
            return row

    # --- execution --------------------------------------------------------------------------------------

    def execute(self, record: DecisionRecord, spec: SymbolSpec, magic: int) -> list[ExecutionOutcome]:
        """Send the orders of an accepted decision: the market part(s) first, then, only when every market
        part is protected, the limit parts of the entry plan. An unknown outcome stops the plan."""
        if record.decision is not Decision.ACCEPT or record.sizing is None or not record.sizing.ok:
            return []
        side = record.signal.side
        if side is None or record.sizing.stop_loss is None:
            return []
        plan_key = record.signal.idempotency_key
        parts = list(enumerate(record.sizing.parts))
        market = [(i, p) for i, p in parts if p.part.order_type is EntryType.MARKET]
        limits = [(i, p) for i, p in parts if p.part.order_type is EntryType.LIMIT]
        outcomes: list[ExecutionOutcome] = []
        for i, part in market:
            outcome = self._execute_part(record, spec, magic, side, plan_key, i, part)
            outcomes.append(outcome)
            if outcome.state is S.UNKNOWN:
                return outcomes  # nothing more is sent until reconciled
        if limits and not (outcomes and all(o.state is S.PROTECTED for o in outcomes)):
            log.warning(
                "plan %s: the market part is not protected; %d limit part(s) not sent",
                plan_key[:12],
                len(limits),
            )
            return outcomes
        for i, part in limits:
            outcome = self._place_limit(record, spec, magic, side, plan_key, i, part)
            outcomes.append(outcome)
    def _patterns(cls, value: list[str]) -> list[str]:
        if any("," in p or p.startswith("!") for p in value):
            raise ValueError("one pattern per entry, without commas or '!' (use exclude for exclusions)")
        return [p.strip() for p in value if p.strip()]

    @property
    def group(self) -> str:
        """The MT5 ``symbols_get(group=...)`` filter: inclusions first, then exclusions (R22)."""
        return ",".join([*self.include, *(f"!{p}" for p in self.exclude)])

def run(mode: TradingMode, broken: set[GateCondition]):  # type: ignore[no-untyped-def]
    live = mode is TradingMode.LIVE
    env_kw: dict[str, object] = {}
    if live:
        env_kw = {"ENABLE_LIVE_TRADING": True, "LIVE_TRADING_CONFIRMATION": confirmation_phrase(LOGIN)}
    else:
        env_kw = {"ENABLE_DEMO_TRADING": True}
    acct_kw: dict[str, object] = {}
    term = TERMINAL
    kw: dict[str, object] = {"risk_config_ok": True, "kill_switch_active": False, "latched_breakers": []}
    for cond in broken:
        where, value = LIVE_INPUTS[cond]
        if cond is G.ENABLE_FLAG and not live:
            value = {"ENABLE_DEMO_TRADING": False}
        if cond is G.ACCOUNT_TRADE_MODE and not live:
            value = {"trade_mode": c.ACCOUNT_TRADE_MODE_REAL}
        if where == "env":
            env_kw.update(value)  # type: ignore[arg-type]
        elif where == "account":
            acct_kw.update(value)  # type: ignore[arg-type]
        elif where == "terminal":
            term = dataclasses.replace(TERMINAL, **value)  # type: ignore[arg-type]
        else:
            kw[where] = value
    return evaluate_gate(mode, env(mode, **env_kw), account=account(mode, **acct_kw), terminal=term, **kw)  # type: ignore[arg-type]

class Clock(Protocol):
    """Injectable time source (real in production, controllable in tests)."""

    def now_utc(self) -> datetime: ...

    def monotonic(self) -> float: ...


class SystemClock:
    def now_utc(self) -> datetime:
        return datetime.now(UTC)

    def monotonic(self) -> float:
        return time.monotonic()


class ManualClock:
    """Test clock that only moves when told to."""

    def __init__(self, start: datetime) -> None:
        if start.tzinfo is None:
            raise ValueError("ManualClock requires an aware datetime")
        self._now = start.astimezone(UTC)
        self._mono = 0.0

    def now_utc(self) -> datetime:
        return self._now

    def monotonic(self) -> float:
        return self._mono

    def advance(self, seconds: float) -> None:
        self._now += timedelta(seconds=seconds)
        self._mono += seconds

    def set(self, when: datetime) -> None:
        delta = (when.astimezone(UTC) - self._now).total_seconds()
        self.advance(delta)


def ensure_utc(dt: datetime) -> datetime:
    if dt.tzinfo is None:
        raise ValueError("naive datetimes are not allowed; use timezone-aware UTC")
    return dt.astimezone(UTC)


def to_epoch(dt: datetime) -> float:
    return ensure_utc(dt).timestamp()

ATR_BARS = 14
HOURS = {Timeframe.H1: 1, Timeframe.H4: 4, Timeframe.D1: 24}


def resample_from_h1(h1: pd.DataFrame, hours: int) -> pd.DataFrame:
    """Bars of ``hours`` from the lane's H1 frame, indexed by each bar's OPEN.

    App frames are stamped at the bar's CLOSE, so the index is shifted back one hour first; the research
    harness reads history stamped at the open and shifts nothing. Getting this backwards costs an hour of
    lookahead, which is how a day of conclusions went wrong on 2026-10-27.
    """
    opens = h1.copy()
    opens.index = pd.DatetimeIndex(opens.index) - pd.Timedelta(hours=1)
    rule = f"{hours}h" if hours < 24 else "1D"
    return opens.resample(rule).agg({"open": "first", "high": "max", "low": "min", "close": "last"}).dropna()


def edge_lean(
    frames: Mapping[Timeframe, pd.DataFrame],
    at: pd.Timestamp,
    entry: Timeframe,
    *,
    frame: Timeframe = Timeframe.H4,
) -> float | None:
    """The signed lean of ``frame``, or ``None`` when it cannot be read from a closed bar.

    ``None`` never means "allowed": a caller that cannot read the frame above its entry has no edge side
    and does not trade. ``entry`` must be smaller than ``frame`` - the rule is meaningless otherwise, and
    a ``ValueError`` here stops it being read from the entry frame by accident.
    """
    if entry.seconds >= frame.seconds:
        raise ValueError(f"the entry frame {entry.value} must be smaller than {frame.value}")
    hours = HOURS.get(frame)
    if hours is None:
        raise ValueError(f"{frame.value} is not read from the H1 frame")

    h1 = frames.get(Timeframe.H1)
    if h1 is None or "close" not in h1:
        return None
    bars = resample_from_h1(h1, hours)
    closed = bars[(bars.index + pd.Timedelta(hours=hours)) <= pd.Timestamp(at)]
    if len(closed) < MEAN_BARS + ATR_BARS:
        return None
    mean = float(closed.close.rolling(MEAN_BARS).mean().iloc[-1])
    width = float(atr(closed.high, closed.low, closed.close, ATR_BARS).iloc[-1])
    if not math.isfinite(mean) or not math.isfinite(width) or width <= 0:
        return None
    lean = (float(closed.close.iloc[-1]) - mean) / width
    # A non-finite lean must never reach a caller: `nan < 0` is False, so a NaN would sail through a
    # gate written as "refuse when the lean is negative" and open a trade on no evidence at all
    # (found by the developer session reviewing this gate while it was live, 2026-10-27).
    # No input reaches it today - every non-finite value is already stopped by the mean and width
    # guards above, and planting a bug here is not caught by any test (plant_bugs_edge.py records
    # that miss on purpose). It is kept as the last line of defence, not as tested behaviour.
    return lean if math.isfinite(lean) else None


def behind(lean: float | None, side: Side) -> float | None:
    """``lean`` seen from a trade's own side: positive means the frame leans the trade's way."""
    if lean is None:
        return None
    return lean if side is Side.BUY else -lean


def edge_side(
    frames: Mapping[Timeframe, pd.DataFrame],
    at: pd.Timestamp,
    entry: Timeframe,
    *,
    frame: Timeframe = Timeframe.H4,
) -> Side | None:
    """The side ``frame`` leans towards, for callers that want one answer rather than the number.

    A lean of exactly zero is on neither side and returns ``None``; the measured rule is "at least 0 on
    the trade's own side", so a strategy that cares about that boundary uses :func:`behind` instead.
    """
    lean = edge_lean(frames, at, entry, frame=frame)
    if lean is None or lean == 0:
        return None
    return Side.BUY if lean > 0 else Side.SELL

def h1_frame(h4_closes: list[float], *, spread: float = 1.0, forming: float | None = None):
    """H1 candles, CLOSE-stamped as the app's frames are, that resample into the given H4 closes.

    Each H4 bar is four H1 bars: the first three sit at the previous close so the H4 close is the value
    asked for, and every bar spans ``spread`` so the ATR is predictable.
    """
    closes: list[float] = []
    for i, value in enumerate(h4_closes):
        previous = h4_closes[i - 1] if i else value
        closes += [previous, previous, previous, value]
    if forming is not None:
        closes += [forming]  # one extra H1 bar: the H4 bar it belongs to has not closed
    # the first H1 bar CLOSES at 01:00, so it opens at 00:00 and its H4 bar opens at 00:00 too
    index = pd.date_range(datetime(2026, 1, 1, 1, tzinfo=UTC), periods=len(closes), freq="1h")
    frame = pd.DataFrame(
        {
            "open": closes,
            "high": [c + spread / 2 for c in closes],
            "low": [c - spread / 2 for c in closes],
            "close": closes,
        },
        index=index,
    )
    return {Timeframe.H1: frame}, pd.Timestamp(frame.index[-1])


def expected_lean(frames, at) -> float:
    """The same number worked out from the resampled frame, independently of the function under test."""
    bars = resample_from_h1(frames[Timeframe.H1], 4)
    closed = bars[(bars.index + pd.Timedelta(hours=4)) <= at]
    mean = closed.close.rolling(MEAN_BARS).mean().iloc[-1]
    width = atr(closed.high, closed.low, closed.close, ATR_BARS).iloc[-1]
    return float((closed.close.iloc[-1] - mean) / width)

The cost is small: update the direct test helper/calls to provide an explicit value (normally `True` for gate truth-table tests), and any external callers will get an immediate `TypeError` until they supply it. ## 2. Whether the gate stops entries and permits position management

**What I checked.** Followed `Orchestrator._decide()` into `DecisionEngine._mode()`, where a missing or failed gate rejects a DEMO/LIVE decision. ## 3. Thai trading day and plan path

**What I checked.** `trading_date()` converts the aware input with `ZoneInfo("Asia/Bangkok")`, then assigns times before `07:00` to the previous date (`day_plan.py:37-38`). I hand-checked 2026-10-27 06:59:59 Thai maps to 2026-10-26 and 07:00:00 Thai maps to 2026-10-27; the equivalent UTC instants, 2026-10-26 23:59:59 UTC and 2026-10-27 00:00:00 UTC, produce the same respective dates. Thailand does not observe daylight saving, and this implementation does not encode a fixed offset.

`Settings.path()` resolves relative paths against `REPO_ROOT` (`app/config.py:1542-1545`), so the default `DAY_PLAN_DIR="data/plans"` resolves to this repository's `data/plans`, independent of the process working directory. That is consistent with the intended location.

**Verdict: date conversion and path resolution are correct.** Coverage is slightly narrower than the brief asks: the unit test checks UTC input but not a non-UTC, non-Bangkok zone. My manual New York check passed. The `datetime.astimezone()` call also assumes an aware datetime; production `Clock` implementations guarantee one, and `ManualClock` rejects a naive start.

## 5. Other live-account concerns; H4 gate fixes

**Clock call.** `Orchestrator.gate()` captures `self.clock.now_utc()` once and uses that same instant for both the plan check and diagnostic path. `SystemClock` returns aware UTC and `ManualClock` stores UTC, so this is sound. If the clock itself raises, the pre-send callback does not proceed to `execution.send()`; the cycle/pre-send fails closed.

**Empty plans.** `DayPlan.exists()` checks `st_size > 0`, so a whitespace-only file is accepted as a plan. If "empty" includes whitespace-only content, this should use a content check such as stripped text; otherwise the current rule is specifically nonzero file presence. `DayPlan.write()` can create a zero-byte file, but that file does not open the gate.

**H4 finite-result guard.** Keep `return lean if math.isfinite(lean) else None` in `app/strategy/edge_side.py:84`. The claim in the implementation comment and `plant_bugs_edge.py` that it is unreachable is too strong: finite close/mean values and a finite, positive but extremely small ATR can overflow the division to infinity. I verified this with the test fixture's finite rising closes and a temporary `atr` result of `1e-320`; `edge_lean()` returned `None` through the final guard. Removing the guard would return infinity, and `infinity < 0` is false, so a negative-only strategy veto could admit a trade without a meaningful lean. The present tests do not exercise this output-overflow case, so the known missed mutation is not evidence that the guard is dead code. Add a focused test if changing the tests is in scope.

The added H4 resampling test does hard-code expected bucket timestamps and highs, so its expected answer is independent. Its code and name/docstring nevertheless claim it does not call `resample_from_h1`; it actually calls that production function and checks the result against the hand-worked expectations. The distinction matters for accurate test descriptions, but the hard-coded assertions do catch a wrong shift (the existing planted-bug output records the shift mutations as caught).

Also isolate the DEMO integration fixture's plan directory so its successful-order test can pass a controlled plan rather than depending on a live date. I would leave both the P26 day-plan gate and H4 edge gate enabled overnight: the Thai trading date intentionally carries the 07:00 plan through the New York session, and I found no reason to disable either gate.
